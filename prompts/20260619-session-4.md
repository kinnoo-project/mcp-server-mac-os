      596 -  pre-tokenized `[]string`. There is no `sh -c`, no string con

          -ied to live under                                             
      599 -  `/bin`, `/sbin`, `/usr/bin`, or `/usr/sbin` before it can ru
          -n — for read-only

          -tage of a

          -n path for                                                    
      602 -  composed stages.

          -xposed without                                                
      604 -  `-exec`, `-delete`, or `-prune`. Any capability that changes

      607 -  meant to be gated by the client's own approval prompt — can

          -annot smuggle in a

          -nst its manifest                                              
      611 -  spec (type, required-ness, enum membership) before any argum
