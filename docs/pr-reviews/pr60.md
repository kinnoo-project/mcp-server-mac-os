# PR #60 review writeup — V3: system keep-awake trio (caffeinate)

Copilot reviewed all 14 changed files and left **2 inline comments**, both on the
new detached-execution engine path. Both were addressed in `c9855c7`.

## Comments and resolutions

### 1. `executor.go:148` — detached child never reaped (zombie leak)
> `execDetached` starts a child process but never calls `Wait()` (it calls
> `Process.Release` instead). On Unix/macOS this can leave zombie processes when
> the detached helper exits, since the parent never reaps the exit status. Reap
> asynchronously so the function can still return immediately while avoiding
> zombie accumulation in a long-running server.

**Addressed (valid).** `execDetached` originally did `Start()` + `Process.Release()`.
`Release()` frees the Go-side handle but does **not** reap the OS process: on Unix
a child a long-running parent never `Wait()`s becomes a zombie when it exits, and
the MCP server would accumulate one process-table slot per keep-awake session over
its lifetime. Replaced `Release()` with an asynchronous reaper —
`go func() { _ = cmd.Wait() }()` — which preserves fire-and-return (the goroutine
blocks only until the child exits, then collects its status). Because the detached
command sets neither `Stdout` nor `Stderr`, both default to `/dev/null`, so there
is no pipe to drain and the `Wait` cannot deadlock. Regression:
`TestExecDetached_ReapsChildNoZombie` starts a short-lived detached child and polls
`syscall.Kill(pid, 0)` until it returns `ESRCH` — a zombie still answers signal 0
(it holds a slot), so the transition to `ESRCH` proves the slot was reclaimed.

### 2. `mutate.go:241` — detach path silently ignores `cmd.Stdin`
> `Command.Detach` is documented as carrying no stdin, but `RunCommand` currently
> ignores `cmd.Stdin` on the detach path. Add an explicit guard so future mutators
> can't accidentally attach stdin to a detached command and silently lose the
> payload.

**Addressed (valid).** The "detached carries no stdin" rule was only a doc comment;
`execDetached` never wires stdin, so a payload set by a future mutator would vanish
without a trace. `RunCommand` now rejects a detached `Command` that carries stdin
with an explicit error before starting anything, turning the contract into an
enforced invariant. Regression: `TestRunCommand_DetachRejectsStdin`.
