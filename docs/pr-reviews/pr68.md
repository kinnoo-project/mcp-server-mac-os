# PR #68 review — build -> main

2026-07-05, mode: fix

Copilot posted a `COMMENTED` review with 3 inline comments on the `build -> main`
integration PR. All three were warranted and addressed.

---

(internal/registry/manifests/system.json) The `allow_sleep` summary said it
"reports that nothing needed changing" when no session is active, but the mutator
(`stageAllowSleep`) actually returns an error in that case. It also claimed to
cancel only "the keep_awake sessions this user started," whereas the
implementation terminates *every* `caffeinate` process owned by the current user
— including ones started outside this tool (e.g. from a terminal).

**fixed**
Rewrote the summary to match the code: it now states that it stops every
caffeinate helper the user is running (cancelling by process, not by session
origin), sends SIGTERM only, and returns an error when no caffeinate session is
active. No behavior change — the manifest text now describes what
`mutate_system_caffeinate.go` actually does.

---

(internal/server/integration_test.go) The tool-surface test asserts each domain
tool's description embeds its operation menu, but the `system` assertion list
was missing several newly added ops (keep_awake, allow_sleep, sleep_assertions,
system_log, thermal_state), so a description-generation regression for those ops
could slip through unnoticed.

**fixed**
Added the five flagged `system` ops to the assertion list. Closed the same
staleness gap across the board while here: extended the `network` list
(trace_route, flush_dns_cache, list_ssh_keys, list_ssh_hosts, ssh_connect) and
`process` list (top_processes), and added op-menu assertions for the three brand
-new domains that previously were only checked for tool *presence*, not their
operation menus — `security` (7 ops), `storage` (8 ops), and `shortcuts` (2 ops).

---

(notes/20260703-capabilities-summary.md) The capabilities summary note was out of
date versus the PR: it claimed 19 domains / 131 operations and omitted the new
`security`, `storage`, and `shortcuts` domains plus new operations across
existing domains.

**fixed**

25 fixed MCP tools (22 domain tools + execute/undo/pipeline). Added table rows for
security, storage, and shortcuts, and expanded the filesystem/system/network/
process rows to mention the newly added operations (image/document conversion,
keep-awake, SSH inventory + staged connect, top-process snapshot, etc.).

Counts were computed directly from `internal/registry/manifests/*.json` (22 files;
171 total operation entries) and cross-checked against the exact 25-tool list
pinned in `internal/server/integration_test.go`.
