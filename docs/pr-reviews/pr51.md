## Comment 1 — mislabeled test never exercised the fallback branch

`internal/engine/builtins_music_test.go` (line 67): the case labeled *"unknown
future state word passes through"* used the input state `fast forwarding`.
`renderNowPlaying` explicitly maps `fast forwarding` → `Fast-forwarding`, so the
case actually tested the humanization *map*, not the fallback it claimed to test
(`verb == "" → verb = state`, which renders an unrecognized state word raw).

**Fix:** split into two cases:
- `fast forwarding is humanized` — pins the map entry (`Fast-forwarding`).
- `unrecognized future state word passes through raw` — uses `seeking` (a word
  the map does NOT contain) and asserts the output is `seeking: Track`, i.e. the
  raw state word passes through verbatim and is not mislabeled `Playing`. This
  genuinely exercises the fallback branch.

Verdict: **valid, non-bug** (test coverage accuracy). The production code was
correct; the test's label overstated what it covered.
