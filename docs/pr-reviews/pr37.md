# PR #37 review — feat(system): machine-info reads (U2)

2026-07-02, mode: fix (Copilot review)

(internal/engine/builtins_sysinfo.go) Four comments, one class: runCommand
reports non-zero exits as data (by design — grep's "no match" is a result),
so sw_vers, system_profiler, df, and softwareupdate failures were silently
rendered as if they were answers — a misleading partial/empty response
instead of a surfaced failure (e.g. a network error during the update check).

**fixed**
Added `commandFailed(tool, res)` — converts a non-zero exit into a real error
carrying the exit code and stderr (falling back to stdout, then "no error
output") — and applied it after every runCommand in the file: both
about_this_mac probes, disk_usage's df, and software_update_check's
softwareupdate. `TestCommandFailed` pins the contract. Live smoke re-run
green (MCP_SYSINFO_LIVE=1).
